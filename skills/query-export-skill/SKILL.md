# query-export-skill

## 목적
분석/검수 결과를 화면 조회와 리포트 생성용으로 실제로 준비한다.  
프로젝트별 손익, 월별 손익, 월간 리포트를 필요에 따라 조회할 수 있게 만들고, 기준 월/합계/프로젝트별 표/전월 대비 증감/요약 문구/생성 시점/기준 정보까지 남긴다.  
노출 범위는 `SPEC.md` §3 결과 노출 정책을 따른다.

## 언제 실행하나
- 분석/검수 결과가 준비된 뒤 실행한다.
- 조회 요청이 있을 때 실행한다.
- 월간 리포트 생성/조회 요청이 있을 때 실행한다.
- 특정 월/시점 기준의 결과를 보고 싶을 때 실행한다.

## 입력
- 조회 조건(기간, 프로젝트, 월 등)
- 리포트 요청
- 선택 월/시점
- 분석 결과(프로젝트별 손익, 월별 손익 등)
- 검수 결과(확정/제외/수정/보류 구분, 검수 대상 목록 등)
- 필요 시 기준 파일 정보, 분석 시점, 생성 시점

## 처리
- 조회 조건에 맞는 데이터를 실제로 준비한다.
  - 프로젝트별 손익
  - 월별 손익
  - 필요 시 기간/프로젝트 필터 적용
- 월간 리포트를 생성/조회용으로 준비한다.
  - 기준 월
  - 합계
  - 프로젝트별 표
  - 전월 대비 증감
  - 요약 문구
  - 생성 시점
  - 기준 정보
- 검수 결과를 반영한다.
  - 확정/제외/수정/보류 구분을 결과에 반영
  - 사람 확인이 필요한 거래가 결과에 어떤 영향을 주는지 볼 수 있게 정리
- 같은 월 데이터가 나중에 추가된 경우, 중복 제외 후 재생성한 결과를 반영할 수 있게 정리한다.
- 결과가 비어 있거나 줄어든 경우에도, 단순히 빈 화면이 아니라 왜 그런지 확인할 수 있는 기준 정보를 함께 남긴다.

## 출력
- 프로젝트별 손익 화면 데이터
- 월별 손익 화면 데이터
- 월간 리포트
- 기준 월/합계/프로젝트별 표/전월 대비 증감/요약 문구/생성 시점/기준 정보
- 조회 조건 대비 결과 범위 안내
- 필요 시 검수 관련 유의 사항

## 산출물
- 프로젝트별 손익 조회용 데이터
- 월별 손익 조회용 데이터
- 월간 리포트
- 기준 정보 및 생성 시점

## 실행 조건
- 분석/검수 결과가 있어야 실행한다.
- 조회 조건 또는 리포트 요청이 있어야 실행한다.
- 조회 조건이 지나치게 좁아서 결과가 없을 때도 “없음”만 반환하지 말고, 어떤 조건으로 조회했고 왜 비어 보이는지 확인할 수 있게 남긴다.

## 결과 전달 방식
- 이 스킬의 결과는 다음 단계로 자동으로 넘겨진다.
- 사용자는 상세 조회 결과를 따로 보지 않고, 최종 결과에서 프로젝트별 손익/월별 손익/월간 리포트를 확인할 수 있게 한다.
- 최종 결과에는 기준 월, 합계, 프로젝트별 표, 전월 대비 증감, 요약 문구, 생성 시점, 기준 정보가 포함된다.

## 재사용성
- 특정 화면 하나에만 종속되지 않고, 프로젝트별/월별/리포트 조회와 생성을 공통으로 처리할 수 있게 만든다.
- 기준 월/시점, 필터 조건, 요약 방식은 나중에 바꿔도 같은 구조를 다시 쓸 수 있게 한다.
- 검수 결과 반영 방식도 규칙에 따라 재사용 가능하게 남긴다.

## 비고
- 이 스킬은 “데이터를 보기 좋게 정리하는 것”만이 아니라, 최종 결과가 어떤 기준으로 만들어졌는지까지 확인할 수 있게 하는 역할이다.
- 최종 결과 확인 화면에서 사용자가 다음 액션을 판단할 수 있도록, 기준 월/시점, 참고한 분석/검수 결과, 유의 사항을 함께 준비한다.

---

## 범위

### 처리하는 것
- 조회 조건(기간/프로젝트/월)에 따른 프로젝트별·월별 손익 데이터 준비
- 월간 리포트 구성: 기준 월, 합계, 프로젝트별 표, 전월 대비 증감, 요약 문구, 생성 시점, 기준 정보
- 검수 결과(확정/제외/수정/보류) 반영
- 화면 표시용 정보 준비(final-assembly가 웹 화면에 조립할 재료)

### 처리하지 않는 것
- **집계 자체의 계산** → analyze-skill. 이 스킬은 이미 집계된 결과를 조회 조건에 맞게 자르고 표현한다
- **화면 조립** → final-assembly(오케스트레이터). 이 스킬은 재료만 준비한다
- **회수 캘린더** → calendar-chatbot-skill
- **결과 없음으로 종료.** 조회 결과가 비어도 조회 조건과 사유를 함께 남긴다

### 제약
- 조회 조건을 임의로 넓히거나 바꾸지 않는다. 조건이 좁아 결과가 비면 조건 그대로 두고 사유를 남긴다
- 어떤 분석/검수 결과를 기준으로 만들었는지 항상 함께 남긴다

## 예시

### 입력

```
조회 조건: 기준 월 = 2026-05, 프로젝트 = 전체
분석 결과: 869건 누적 기준
검수 결과: 자동 처리 808 / 사람 확인 필요 57 / 보류 4   ※ 분할값은 형식 예시
```

### 출력 (2026-05 월간 리포트)

```
기준 월: 2026-05
합계    매출 206,900,000원 / 매입 122,835,569원 / 손익 84,064,431원
전월 대비  매출 +146,949,894원 (+245.1%)
           매입  +23,154,167원 (+23.2%)
           손익 +123,795,727원 (적자 -39,731,296 → 흑자 84,064,431 전환)
```

| 프로젝트/현장 | 매출 | 매입 | 손익 |
|---|---:|---:|---:|
| 2026도두항부잔교설치공사 | 60,000,000 | — | — |
| 2026 여수 신북항 해경선 접안시설 | 68,800,000 | — | — |
| 2025 항만시설 유지보수공사 | 42,350,000 | — | — |
| 추자 예초 해상부유구조물 | 22,000,000 | — | — |
| 운진항콘트리트부잔교보수공사 | 13,750,000 | — | — |

```
요약 문구: 2026년 5월 매출 2억 690만원으로 5개월 중 최대. 전월 적자에서 흑자 전환.
           도두항·여수 신북항 2개 현장이 매출의 62.3%를 차지.
생성 시점: 2026-08-06T14:20:24+09:00
기준 정보: Transaction 869건 누적 / 검수 반영분 808건 / 보류 4건 미반영   ※ 808·4는 형식 예시값
유의 사항: 사람 확인 필요 57건이 미확정 상태로, 확정 시 프로젝트별 손익이 변동될 수 있음
```

진행 표시: `결과 정리 완료 — 5개월, 프로젝트 22건`

### 결과가 비어 보이는 경우

```
조회 조건: 기준 월 = 2026-02, 프로젝트 = 전체
출력:
  매출 0원 / 매입 92,578,174원 / 손익 -92,578,174원
  안내: 2026-02의 매출은 0원입니다. 데이터 누락이 아니라 해당 월 세금계산서 발행이
        없었기 때문입니다. 기준 데이터는 869건 전량이며 2월 매입 거래는 정상 반영됐습니다.
```

빈 화면을 그대로 반환하지 않고, 조회 조건과 사유를 함께 남기는 것이 이 스킬의 요구사항이다.

## 성공 기준

- [ ] 2026-05 합계가 매출 206,900,000 / 매입 122,835,569 / 손익 84,064,431로 출력된다
- [ ] 전월 대비 증감이 금액과 비율로 함께 출력된다
- [ ] 기준 월, 합계, 프로젝트별 표, 전월 대비, 요약 문구, 생성 시점, 기준 정보 7개 항목이 모두 있다
- [ ] 2026-02 조회 시 빈 결과가 아니라 매출 0 + 사유 안내가 출력된다
- [ ] 사람 확인 필요 57건이 미확정임을 유의 사항으로 알린다
- [ ] 반영 건수 + 미확정 + 보류의 합이 누적 869건과 일치한다
- [ ] 어떤 분석/검수 결과를 기준으로 만들었는지(건수 포함) 출력에 남는다
- [ ] 조회 조건이 입력값과 동일하게 유지된다(임의 확장 없음)
